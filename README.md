# RideShare Mobile

Projekt Next.js për ushtrimin e Javës 3: lista e udhëtimeve, faqja e
detajeve dhe kërkesa e simuluar për një vend.

Punuar nga **Gent Emini**.

Repository: https://github.com/gentemini44-Cpt/rideshare-mobile
Demo për telefon: https://rideshare-mobile-blush.vercel.app

## Nisja lokale

```bash
cd aplikacioni
npm install
npm run dev
```

Pastaj hap [http://localhost:3000](http://localhost:3000).

## Në telefon

Hape demo-n me HTTPS në Chrome (Android) ose Safari (iPhone). Në Chrome
zgjidh **Install app** ose **Add to Home screen** nga menyja; në Safari
zgjidh **Share → Add to Home Screen**. RideShare është një PWA, prandaj
hyn nga ekrani kryesor pa u instaluar nga App Store ose Play Store.
